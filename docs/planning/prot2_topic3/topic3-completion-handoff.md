# Topic 3 最小実装完了メモ

作成日: 2026-05-27

## 概要

Topic 3「イベントと特殊部屋」は、最小実装として宝物部屋と回復の泉が動く状態まで到達した。

イベントは1フロア最大1つの低確率出現とし、通常探索を壊さない範囲で、見た目、ログ、SE、報酬、回復を追加している。

## 実装済み

- イベント部屋用の `state.eventRooms`。
- イベントオブジェクト用の `state.eventObjects`。
- 階層別イベント抽選テーブル。
- 宝物部屋。
- 宝物部屋の追加アイテム配置。
- 回復の泉。
- 泉の1回だけのHP回復。
- イベント部屋の淡い床光。
- 泉オブジェクトのCanvas描画。
- イベント発見時のログ、SE、フラッシュ。
- 泉発動時のログ、SE、浮遊テキスト、フラッシュ。
- イベントオブジェクトと敵、アイテム、階段、開始位置の重なり回避。
- README更新。
- 手動テストチェックリスト更新。

## 現在のイベント出現方針

- 1F: 18%。
- 2Fから3F: 28%。
- 4F以降: 35%。
- 出現する場合、宝物部屋または回復の泉のどちらか。
- 開始部屋、階段部屋、それらと矩形が重なる部屋、小さすぎる部屋は候補から外す。

## 宝物部屋

- 部屋の床に淡い金色の光を重ねる。
- 追加アイテムを2個配置する。
- 報酬は通常テーブルより少しだけ良い比率にしている。
- 鉄の剣は確定ではない。
- 初回侵入時にログ、SE、フラッシュを出す。

## 回復の泉

- 部屋中央付近に泉を1つ置く。
- 泉に乗ると、HPが減っている場合に1回だけ回復する。
- 回復量は `max(8, 最大HPの35%)`。
- 満腹度は回復しない。
- HP満タン時は使用済みにせず、後でHPが減ってから使える。
- 使用済みの泉は見た目を暗くし、再回復しない。

## 確認済み

- `node --check main.js` は通過。
- スタブ環境で1Fから5Fを各120回、合計600フロア生成確認した。
- 生成確認で、イベント部屋は最大1つに収まった。
- 生成確認で、泉、敵、アイテム、階段、開始位置の重なりは発生していない。
- 生成確認で、イベント部屋が開始位置や階段位置を含まないことを確認した。
- 泉の発火確認で、最大HP40、HP10からHP24へ回復することを確認した。
- 使用済みの泉で再回復しないことを確認した。

## 未確認

- この環境ではブラウザ自動化ツールが見つからなかったため、ブラウザ上の見た目確認は未実施。
- 実プレイでのイベント出現頻度の体感調整は未実施。
- SEの聞こえ方は実ブラウザでの確認が必要。

## 残した判断

- モンスターハウス、罠部屋、強敵の気配は今回の最小実装から外した。
- 泉は隣接して使う形式ではなく、乗ると発動する形式にした。
- 宝物部屋のレア演出は、アイテム個別の強い発光ではなく部屋の床光に留めた。
- 専用SVG素材は追加せず、泉はCanvas描画で実装した。
