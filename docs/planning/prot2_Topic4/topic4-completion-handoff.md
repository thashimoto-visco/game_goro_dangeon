# Topic 4 最小実装完了メモ

作成日: 2026-07-10

## 概要

Topic 4「強敵と階層メリハリ」は、ミニ悪魔ちゃんを使った最小実装まで完了した。

強敵をモンスター種の恒久属性にはせず、出現時の `encounterRank` として実装した。同じミニ悪魔ちゃんを5Fでは `strong`、将来の10F相当では `normal` として生成できる。

5F固定は動作確認しやすくするためのテーブル設定であり、汎用ロジックは階層番号5や `miniDevil` を知らない。

## データ上のMVP設定

- 階層: 5F。
- 出現率: 100%。
- 敵種: `miniDevil`。
- 遭遇ランク: `strong`。
- 強敵部屋: 開始部屋、階段部屋を除き、遭遇テーブルの `minRoomW` / `minRoomH` 以上の部屋。5FのMVP値は5×4。
- 素のミニ悪魔ちゃん: HP `10 + 階層補正`、攻撃 `5 + 階層補正`、経験値10。
- 5F強敵個体: HP21、攻撃8、経験値18。
- 確定報酬: 薬草40%、鉄の剣35%、おにぎり25%。

## 配置フォールバック

開始部屋と階段部屋以外に有効な部屋がない場合、強敵を無理に置かない。

2部屋のフォールバックマップで階段部屋へ配置すると撃破必須になり、「避ける」選択を壊すためである。進行可能性を優先し、そのフロアでは特殊遭遇をスキップする。

200件のシード固定レイアウトで配置率を監視し、75%以上をテスト基準としている。現在の5×4以上の候補条件では200件中200件で配置できた。

## メッセージ追加方法

敵種の標準文言は `monster-catalog.js` の `messages` に置く。

```js
messages: {
  floorPresence: "階開始時の予兆",
  roomPresence: "部屋発見時の予兆",
  encounter: "通常個体の初回視認",
  strongEncounter: "強敵個体の初回視認",
}
```

特定の遭遇だけ文言を変える場合は、特殊遭遇entryの `messages` で上書きする。

優先順位:

1. 強敵なら `strongEncounter`、通常個体なら `encounter` というランク対応キーを先に選ぶ。
2. 同じキーでは、特殊遭遇entry、モンスターカタログ、遭遇ランク共通の順に解決する。
3. ランク固有キーがなければ、通常の `encounter` を同じ順序で解決し、最後に通常共通文言へフォールバックする。

## デバッグ確認方法

`file:`、`localhost`、`127.0.0.1`、`::1` のローカル実行時だけ、URLクエリで確認状態を作れる。GitHub Pagesなど公開ホストでは `debug=1` を指定しても無視する。

- `?debug=1&floor=5`: 5Fから開始。
- `?debug=1&floor=5&encounter=1`: 強敵の近くから開始。
- `?debug=1&floor=5&encounter=1&loadout=1`: レベル3、鉄の剣装備で強敵の近くから開始。

通常URLではデバッグ開始位置や装備変更は有効にならない。

## 2026-07-13 コードレビュー対応

- 重み付き抽選が空または不正なentryを返した場合の敵・アイテム生成を安全に打ち切るようにした。
- 特殊遭遇の敵配置に失敗した場合は予約した強敵部屋を解除し、通常の宝物部屋／泉抽選へ戻すようにした。
- 部屋色、発見SE、フラッシュ、階開始SEを `encounterRank` に応じて切り替え、通常ランクを強敵扱いしないようにした。
- デバッグクエリを起動時に一度だけ解析し、ローカル実行時だけ有効にした。
- 強敵用のランク固有メッセージが、敵カタログの通常遭遇文言に隠れない解決順へ変更した。
- 特殊遭遇側の重み付き抽選、階層テーブル検索、部屋適格判定を共通処理から注入し、重複実装をなくした。
- 最小部屋サイズを遭遇テーブルの `minRoomW` / `minRoomH` へ移し、別階層・別敵で調整可能にした。
- デバッグ装備変更を専用関数へ集約し、テスト共通ヘルパーを `tests/test-helpers.js` へまとめた。

## 残した判断

- 5Fの100%出現はMVP検証設定。体感確認後に出現率や階層をデータで変更してよい。
- ミニ悪魔ちゃんは強敵専用画像にせず、将来の通常敵化を前提にした。
- 強敵専用表現は本体SVGではなく、遭遇ランク側のCanvas演出へ置いた。
- プレイヤーの現在HPによって報酬ランクを変えない。ランクは生成時に確定する。
- 特殊AI、遠距離攻撃、状態異常はTopic 6へ残した。
- 新しい強敵専用アイテムはTopic 5へ残した。
- 強敵BGMは追加せず、Web Audioの短い専用SEに留めた。

## 2026-07-13 操作フィードバック対応

- 特殊遭遇の敵は割り当てられた部屋内だけを移動し、プレイヤーを追って通路へ出ないようにした。
- 部屋を横方向に並べた一本道の両端へ開始地点と階段を固定する生成をやめた。
- 既存の接続を維持しつつ65%の確率で非隣接部屋間に追加通路を作り、ループのあるフロアも生成するようにした。
- 開始部屋をランダム化し、階段部屋は一定以上離れた複数候補から選ぶようにした。強敵部屋が必須経路になる場合はアンラッキーとして許容し、回避可能性は保証しない。
- ミニ悪魔ちゃんSVGを、紫色の顔中心の形から、暗赤・黒・橙を使った二頭身の小悪魔少女型へ全面的に描き直した。フォールバックCanvas形状も同じ配色と人型シルエットへ寄せた。
- 空腹度は変更せず、経路固定の解消後に改めて体感を確認する。
