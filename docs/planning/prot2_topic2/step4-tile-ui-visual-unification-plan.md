# Step 4: タイルとUIの統一

作成日: 2026-05-27

## 目的

既存敵と既存アイテムのリッチ化後に、探索画面の土台である床、壁、階段、HTML UI、Canvas内UIの見た目をそろえる。

このStepでは、タイルを主役にしすぎない。敵、アイテム、吾郎が読みやすい状態を保ちながら、画面全体の素材混在感を減らす。

## 前提

- 床、壁、階段はいずれも `32x32` SVGで用意されている。
- 床と壁は、それぞれ3種類のバリエーションがあり、座標ベースで安定して切り替わる。
- 階段は `stairs_down.svg` をタイル全体に描画しているが、見た目上は小さめの階段として扱われている。
- HTML UIは `styles.css`、Canvas内メニューと全滅画面は `main.js` で別々に描画している。
- ReactなどのUIフレームワークは、このTopicでは導入しない。

## 方向性

### タイル

- 床は敵とアイテムを邪魔しない暗さを維持する。
- 床の情報量は増やしすぎず、探索の単調さを軽く減らす程度にする。
- 壁は床より暗く、境界が分かる状態を保つ。
- 壁の上端/底辺の重さを少し出し、通路と部屋の輪郭を読みやすくする。
- オートタイルの完全実装はしない。

### 階段

- 階段はアイテムより重要な目的地として、床上で埋もれないようにする。
- 現状の青い階段の方向性は維持してよい。
- ただし、光りすぎてアイテムや敵を邪魔しない。
- 必要なら、階段まわりの淡い光や輪郭を追加する。

### HTML UI

- 現在の金色枠、暗いパネル、角丸小さめのSFC風は維持する。
- ステータス欄、持ち物、ログの背景と枠を整理する。
- HP、満腹度、経験値、装備が読みやすいことを優先する。
- 装飾を増やしすぎず、ゲームプレイ中に目が疲れないようにする。

### Canvas内UI

- 持ち物メニュー、全滅画面の背景、枠、選択カーソルをHTML UIに寄せる。
- Canvas内UIだけ別ゲームに見えないようにする。
- 文字サイズは現状の読みやすさを維持する。
- キーヒントや説明文は必要最小限のままにする。

## 作業範囲

- 床タイル3種の色、陰影、ノイズ量の調整。
- 壁タイル3種の色、境界、重さの調整。
- 階段タイルの視認性調整。
- `drawStairsLayer()` の階段表示補助の検討。
- `styles.css` のパネル、ステータス、持ち物、ログの統一。
- `drawInventoryMenu()` の枠、背景、カーソルの統一。
- `drawGameOverLayer()` の枠、背景、文字色の統一。

## 非スコープ

- マップ生成ロジックの変更。
- 部屋/通路ごとのタイル専用ルールの本格実装。
- オートタイルの完全実装。
- タイトル画面、リザルト画面の追加。
- UIフレームワークの導入。
- レスポンシブレイアウトの全面作り直し。

## 実装タスク

1. 現行タイル3種、壁3種、階段の画面内での見え方を確認する。
2. 床タイルの明度と情報量を調整する。
3. 壁タイルの暗さ、境界、重さを調整する。
4. 階段タイルを、目的地として分かりやすい見た目に調整する。
5. 必要なら `drawStairsLayer()` に淡い光や影を追加する。
6. HTML UIのパネル、ステータス、持ち物、ログの色を整理する。
7. Canvas内持ち物メニューの背景、枠、選択行をHTML UIに寄せる。
8. 全滅画面の背景、枠、文字色をCanvas内メニューと揃える。
9. 1Fから数階層を歩き、敵、アイテム、階段、UIが同時に見える状態を確認する。
10. Step5の基準整理へ渡すメモを残す。

## 受け入れ条件

- 床と壁の境界が分かりやすい。
- 床タイルが敵やアイテムの視認性を邪魔しない。
- 階段が目的地として見つけやすい。
- HTML UIとCanvas内UIの雰囲気が近づいている。
- ステータス、ログ、持ち物、全滅画面の文字が読みやすい。
- Topic 1のゲーム進行、Topic 2 Step2/Step3の敵・アイテム視認性を壊していない。

## 手動確認

### タイル

- 1Fで床と壁の境界を確認する。
- 部屋、通路、入口付近で壁が読みやすいか確認する。
- 敵やアイテムが床模様に埋もれないか確認する。
- 階段が遠目でも分かるか確認する。

### UI

- ステータス欄でHP、満腹度、経験値、装備を確認する。
- 持ち物欄でアイテム名と装備中表示を確認する。
- ログが長くなっても読めるか確認する。
- Canvas内持ち物メニューを開き、選択行と説明文を確認する。
- 全滅画面で死因、階層、レベル、撃破数を確認する。

### 回帰

- 移動、攻撃、拾得、使用、装備、階段移動が動く。
- レベルアップ、自然回復、全滅表示が壊れていない。

## Step 5への引継ぎ

Step 4後は、敵、アイテム、タイル、UIを同時に見た状態で基準を整理する。

Step 5では次を確認する。

- 今後の追加敵が守るべき見た目密度。
- 今後の追加アイテムが守るべき視認性。
- タイルがどこまで主張してよいか。
- UIの色、枠、文字サイズの基準。
