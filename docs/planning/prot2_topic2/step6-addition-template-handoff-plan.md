# Step 6: 追加用ひな形と完了メモ

作成日: 2026-05-27

## 目的

Step 2からStep 5で得た暫定基準をもとに、新規敵/新規アイテムを追加する時に使う作業ひな形を作る。

このひな形は確定仕様ではない。Topic 2時点での暫定版として、今後の追加作業で迷いにくくするためのものとする。

## 前提

- 敵は、吾郎と並べても仮素材に見えない程度の密度を目指す。
- 既存3敵は、かわいらしさを優先した。
- ゴーレムは、かわいさを残しつつ強敵感を出す方向にした。
- アイテムは、敵より小さく、床上で見分けやすいことを優先した。
- タイルとUIの調整は暫定であり、確定基準ではない。
- サイズ、形式、演出は今後のTopicで見直してよい。

## 追加時の暫定ルール

### 敵

- まず既存3敵と同じ画面に置いた時の密度を確認する。
- 通常敵はかわいさ、分かりやすいシルエット、軽い2コマ相当アニメを基本にする。
- 強敵は通常敵より大きく、影や警告演出で危険度を出す。
- ステータスや経験値は、初出階層での体感を基準にする。
- 素材サイズや描画サイズは固定しすぎず、ゲーム画面で確認して決める。

### アイテム

- 敵より主張を弱め、床上の拾得物として見せる。
- 種別は色だけでなく形で分ける。
- 強いアイテムは出現率を低くするか、初出階層を遅らせる。
- アイテム数が増えるまでは、種別共通アイコンでもよい。
- アイテム数が増えたら個別アイコン化を再検討する。

## Topic 2完了メモ

Topic 2では、グラフィックス基準の再整理として、以下を実施した。

- 現状アセット棚卸し。
- 既存敵3種のリッチ化。
- 既存敵の2コマ相当待機アニメーション。
- 既存アイテム3系統のリッチ化。
- アイテムの淡い光、影、フォールバック形状の調整。
- 床、壁、階段タイルの軽い調整。
- 階段の淡い光追加。
- HTML UIとCanvas内UIの軽い統一。
- 現時点の暫定基準整理。
- 新規敵/新規アイテム追加用の暫定ひな形作成。

## 残した判断

- タイルパターン単体の調整は、画面印象への効きが弱かった。
- 今後の大きな見た目改善は、部屋/通路の明暗差、照明、特殊部屋、階層テーマで検討する。
- アイテムは現時点では種別共通アイコンでよいが、種類が増えたら個別化を検討する。
- UIフレームワーク導入は、Topic 2では見送る。タイトル、リザルト、図鑑などが増えるTopicで再検討する。

## 次Topicへの引継ぎ

Topic 3「イベントと特殊部屋」では、以下を意識する。

- 宝物部屋や回復の泉は、通常床と少し違うアクセントを入れる。
- イベント部屋の見た目は、タイルパターンより照明や色味の差で出すとよさそう。
- イベント用アイコンやオブジェクトは、既存アイテムより少し大きくしてよい。
- ログ、SE、淡い光を組み合わせて、イベント発生を分かりやすくする。
- 既存の敵/アイテム/階段の視認性を邪魔しない。

- 新規敵追加ひな形がある。
- 新規アイテム追加ひな形がある。
- ひな形が暫定基準であることが明記されている。
- Topic 2の実施内容と残した判断が整理されている。
- Topic 3への引継ぎが整理されている。
