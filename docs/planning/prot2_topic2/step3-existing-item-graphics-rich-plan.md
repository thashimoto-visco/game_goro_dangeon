# Step 3: 既存アイテムグラフィックのリッチ化

作成日: 2026-05-27

## 目的

現状の武器、食料、回復アイテムを、床上で見分けやすくする。

敵グラフィックはStep2で吾郎に近い密度へ寄せたが、アイテムは敵ほど大きく主張させない。探索中に見落としにくく、拾う前に種別が分かることを優先する。

## 前提

- 現在のアイテムは `weapon`、`food`、`potion` の3系統アイコンで表示している。
- `woodenSword` と `ironSword` は、現時点では武器系アイコンを共有する。
- `riceBall` は食料系、`herb` は回復系として扱う。
- 新規アイテム追加用ひな形はまだ作らない。既存アイテムの実画面確認後に整理する。

## 見た目の方向性

### 共通

- 敵より小さく、床上の拾得物として見える。
- 床や階段に埋もれない明度と輪郭にする。
- 色だけでなく形で種別を判別できるようにする。
- 吾郎や敵より情報量は控えめにする。
- 影と淡い光で、拾えるものだと分かるようにする。

### 武器系

- 斜めの剣/棒として、細すぎないシルエットにする。
- 刃、柄、ハイライトを分ける。
- 食料や回復と誤認しない硬い形にする。

### 食料系

- おにぎりとして分かる三角形を優先する。
- 白い本体、黒い海苔、米粒の影で識別性を上げる。
- 暗い床で白が飛びすぎないように輪郭を入れる。

### 回復系

- 現状の `potion` アイコン名は維持しつつ、薬草/回復系として見える方向に寄せる。
- 緑の葉と小瓶の要素を組み合わせ、食料やスライムと紛れにくくする。
- HP回復アイテムとして、柔らかい回復色を使う。

## 作業範囲

- `item_weapon.svg` のリッチ化。
- `item_food.svg` のリッチ化。
- `item_potion.svg` のリッチ化。
- 床上アイテム描画のサイズ、影、淡い光の調整。
- フォールバック描画の種別差の調整。

## 非スコープ

- 新規アイテムの追加。
- アイテム効果や出現率の変更。
- 武器ごとの個別アイコン化。
- 新しいアイテム種別の追加。

## 実装タスク

1. 既存3系統アイコンを確認する。
2. 武器系アイコンを、細すぎない剣/棒としてリッチ化する。
3. 食料系アイコンを、おにぎりとして分かりやすくする。
4. 回復系アイコンを、薬草/回復系として分かりやすくする。
5. 床上描画サイズと影を調整する。
6. 種別ごとの淡い光を調整する。
7. フォールバック描画でも種別が分かるようにする。
8. 1Fから数階層で床上表示、拾得、持ち物表示を確認する。

## 受け入れ条件

- 武器、食料、回復が床上で見分けられる。
- アイテムが床や階段に埋もれない。
- アイテムが敵より主張しすぎない。
- 拾得ログ、持ち物表示、使用/装備処理が壊れていない。
- Topic 1の階層別アイテム出現が壊れていない。

## Step 4への引継ぎ

アイテムの視認性が整った後、タイルと階段を調整する。

タイル側では、アイテムが埋もれない暗さと情報量を維持する。
