# バランス調整パス1 完了メモ

完了日: 2026-08-20

## 実装内容

### 食料出現率

- 1Fのおにぎり30%は変更なし。
- 2–3Fのおにぎりを24%から30%へ変更。
- 4F以降のおにぎりを16%から20%へ変更。
- 4F以降の大きいおにぎりを6%から10%へ変更。
- 2F以降の通常配置に占める食料率を合計30%に統一。
- おにぎりの回復量35、大きいおにぎりの回復量60と最大満腹度+5は変更なし。
- 宝物部屋と強敵報酬のテーブルは変更なし。

### 回復の泉

- 従来どおりHPを `max(8, 最大HPの35%)` 回復。
- 満腹度を固定値ではなく、現在の最大満腹度まで全回復。
- 大きいおにぎりで最大満腹度が増えている場合も、その最大値まで回復。
- 泉は最大満腹度自体を増やさない。
- HPまたは満腹度の一方でも不足していれば使用可能。
- HPと満腹度が両方最大なら泉を消費しない。
- HPだけ、満腹度だけ、両方を回復した場合に対応するログと浮遊テキストを表示。
- 使用済みの泉は再使用不可。

### 敵の圧力

- ゴロ岩ゴーレムの `atkScale` を0.60から0.70へ変更。5Fの通常個体は攻撃6から7。
- どくトカゲの `atkScale` を0.45から0.55へ変更。4F個体は攻撃4から5。
- ぷくぷくキノコの `atkScale` を0.35から0.45へ変更。5F個体は遠距離攻撃3から4。
- スライム、コウモリ、強敵ミニ悪魔ちゃんは変更なし。
- 敵数、敵HP、経験値、毒の確率は変更なし。

## テスト

- 階層別アイテムテーブルのweight合計100を確認。
- 1F、2–3F、4F以降の食料率30%を固定値テストで確認。
- 4F以降の大きいおにぎり10%を確認。
- 泉による現在の最大満腹度までの全回復を確認。
- 最大満腹度105の状態でも105まで回復することを確認。
- HPと満腹度の同時回復、両方最大時の未使用、使用済み泉の再利用不可を確認。
- 対象敵の階層別攻撃値と、1Fスライム・2Fコウモリが変わらないことを確認。
- 全9テスト、JavaScript構文検査、`git diff --check` が通過。

## プレイ確認で見ること

- 空腹死が通常プレイの最多死因ではなくなるか。
- 食料を無計画に使った場合の空腹リスクは残っているか。
- 泉を見つけたとき、食料を温存して泉を先に使う判断が生まれるか。
- 4F以降の敵強化が、増えた継戦能力に対して適度な圧になっているか。
- 食料が余りすぎる場合でも、すぐweightを戻さず複数回の偏りを確認する。

空腹死がまだ多い場合は、食料率をさらに上げる前に、連続して食料が出なかった場合の救済配置を検討する。
