# 中期バックログ

## 目的

中期ロードマップに入れきれなかった候補や、優先度がまだ低いものを残す。

ここにある項目は捨てない。ただし、すぐ実装する対象ではなく、次の詳細プラン作成時に必要に応じて拾う。

- 敵ごとの専用攻撃エフェクト
- 敵ごとの撃破アニメーション

- フロアテーマ: 岩場
