# Phase 7 詳細プラン: 持ち物メニューと操作UI

## Phase 7の目的

Phase 4で持ち物と装備が入り、Phase 6で音と基本バランスが整った。次は、数字キーだけに頼っている持ち物操作を、画面上で分かるメニュー操作へ拡張する。

目標は、トルネコ/シレン系らしい「アイテムを選んで、使う/装備する/見る/捨てる」を実現すること。ただし最初から複雑にせず、Phase 7では軽いメニューと入力整理に集中する。

## 現状

- アイテム上に乗ると自動で拾得する。
- 持ち物は右パネルに表示される。
- `1`-`9` で該当アイテムを即使用/装備する。
- 装備中武器は持ち物内に残る。
- アイテム詳細、捨てる、キャンセル、選択カーソルは未実装。

## スコープ

## 操作方針

Phase 7では既存の数字キー即使用を残しつつ、メニュー操作を追加する。

候補:

- `I`: 持ち物メニューを開く/閉じる
- `ArrowUp` / `ArrowDown`: 選択移動
- `Enter`: 使う/装備する
- `D`: 捨てる
- `Escape`: 閉じる

既存操作との関係:

- 通常時の矢印/WASDは移動。
- メニュー中の矢印はカーソル移動。
- メニュー中は足踏み、移動、攻撃、数字キー使用を受け付けない。
- 使用/装備/捨てるが確定したらメニューを閉じる。
- 使用/装備は1ターン消費する。
- 捨てるはPhase 7では1ターン消費しない方針にする。必要なら後で調整する。

## UI方針

まずはcanvas内に半透明パネルを重ねる。

理由:

- 右パネルだけよりゲーム中の状態として分かりやすい。
- ゲームオーバーオーバーレイと同じ描画パターンを流用できる。
- HTMLの大幅な変更を避けられる。

表示内容:

- 見出し: `持ち物`
- アイテム一覧
- 装備中マーク
- 説明文
- 操作ヒント: `Enter: 使う/装備  D: 捨てる  Esc: 閉じる`

空の場合:

- `持ち物はない`
- `Esc: 閉じる`

## 状態設計

`state.menu` を追加する。

```js
menu: {
  type: null,
  selectedIndex: 0,
}
```

候補:

- `type: null`: メニューなし
- `type: "inventory"`: 持ち物メニュー

入力受付:

```js
function isMenuOpen() {
  return Boolean(state.menu.type);
}
```

`canAcceptInput()` は、通常行動に対して `!state.action && !state.gameOver.active && !isMenuOpen()` にする。

## 捨てる仕様

選択中アイテムを床へ置く。

条件:

- プレイヤー足元に床アイテムがない場合、足元へ置く。
- 足元にすでに床アイテムがある場合、捨てられない。
- 隣接4方向への配置はしない。
- 装備中武器を捨てた場合、装備解除する。

ログ:

- `木の棒を置いた。`
- `足元に物があって置けない。`

理由:

- 隣接4方向へ置く操作は、実質的に方向指定の「投げる/置く」に近い。
- 移動先に置くと、自動拾得仕様によって再度拾ってしまう挙動が起きやすい。
- Phase 7では「捨てる」は足元へ置くだけに限定し、方向指定や投げる操作は別スコープに分ける。

将来候補:

- `T`: 投げる
- 方向キーで投げる方向を指定
- 敵に当たる、壁で止まる、床に落ちる

## サウンド

Phase 6の音基盤を使う。

- メニュー開閉: 決定音または短いUI音
- カーソル移動: 小さなクリック
- 使用/装備: 既存の `use`
- 捨てる: 低めの短音
- 失敗: 低い短音

必要なら `playSound("menu")`, `playSound("cursor")`, `playSound("drop")`, `playSound("fail")` を追加する。

## 受け入れ条件

- `I` で持ち物メニューを開閉できる。
- メニュー中にカーソル移動できる。
- 選択中アイテムの名前と説明が見える。
- `Enter` で使用/装備できる。
- `D` でアイテムを足元に置ける。
- 足元にアイテムがある場合、`D` で置けない。
- 装備中武器を置くと装備が外れる。
- メニュー中に移動や攻撃が暴発しない。
- 空の持ち物でも表示が破綻しない。
- ゲームオーバー中はメニューを開けない。
- 既存の数字キー即使用も引き続き動く。

## 手動テスト項目

- アイテムを拾う。
- `I` でメニューを開く。
- 上下で選択を変える。
- 武器を選んで `Enter` で装備する。
- 食料/回復薬を選んで `Enter` で使用する。
- アイテムを選んで `D` で床へ置く。
- 足元にアイテムがない状態で捨てる。
- 足元にアイテムがある状態で捨てられないことを確認する。
- 持ち物が空の状態でメニューを開く。
- メニュー中に矢印キーを押しても移動しない。
- `Escape` で閉じる。
- ゲームオーバー中に `I` を押しても開かない。

## リスクと対策

### リスク: 入力分岐が複雑になる

対策:

- `handleMenuInput(key)` と `handleGameInput(key)` に分ける。
- `keydown` の先頭でゲームオーバー、メニュー、通常入力の順に分岐する。

### リスク: 捨てたアイテムを即拾い直す

対策:

- Phase 7の捨てるは足元配置だけにする。
- 足元にすでにアイテムがある場合は失敗させる。
- 方向指定の「投げる」は別Phaseで扱う。

### リスク: メニューが戦闘演出と衝突する

対策:

- `canAcceptInput()` がfalseの間はメニューを開けない。
- メニュー中は `state.action` を開始しない。
