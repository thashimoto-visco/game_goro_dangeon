# 手動テストチェックリスト

## 起動

- `index.html` をブラウザで開ける。
- コンソールにerror/warningが出ない。
- 画面にゲーム画面、ステータス、持ち物、ログ、音ボタンが表示される。
- 初期状態で音ボタンが `音 OFF` になっている。
- ステータスに階層、レベル、HP、攻撃、守備、満腹度、経験値、装備が表示される。

## 基本操作

- 矢印キーまたはWASDで移動できる。
- 移動に合わせてカメラがスクロールする。
- `Space` で足踏みできる。
- 壁には移動できない。

## 戦闘

- 隣接する敵方向へ移動入力すると通常攻撃になる。
- 攻撃モーション、斬撃、ヒット表示が出る。
- 敵が生きている場合、反撃が発生する。
- 敵を倒すと撃破演出とログが出る。
- 敵種ごとにHP/攻撃力の違いが感じられる。

## レベルと経験値

- 敵を倒すと経験値が増える。
- 敵種ごとに獲得経験値が異なる。
- 経験値が必要値に達するとレベルアップする。
- レベルアップ時にHPが最大まで回復する。
- レベルアップ時に最大HP、攻撃、守備が更新される。
- レベルアップ時にログ、浮遊テキスト、SE、フラッシュが出る。
- ステータスのレベル、経験値、次レベルまでの表示が更新される。
- リトライ時にレベルと経験値が初期化される。

## アイテム

- 床アイテムが見える。
- アイテム上に移動すると拾える。
- 拾ったアイテムが持ち物に表示される。
- `I` で持ち物メニューを開ける。
- 持ち物メニュー内で上下キーの選択移動ができる。
- 持ち物メニューから `Enter` で使用/装備できる。
- 持ち物メニューから `D` で足元へ置ける。
- 足元にアイテムがある場合、`D` で置けない。
- `Escape` で持ち物メニューを閉じられる。
- 持ち物メニュー中に移動や攻撃が暴発しない。
- `1`-`9` で武器を装備できる。
- `1`-`9` で食料と回復薬を使える。
- 持ち物が9個のとき、追加アイテムを拾えない。
- 階段とアイテムが同じマスに出ない。

## 階段

- 階段に乗ると次の階へ進む。
- 次の階で床アイテムと敵が再配置される。
- 持ち物と装備は階層移動後も維持される。

## 自然回復

- 満腹度90以上では自然回復が早い。
- 満腹度70から89では自然回復する。
- 満腹度30から69では自然回復が遅い。
- 満腹度29以下では回復進捗が増えない。
- 満腹度0では空腹ダメージのみで自然回復しない。
- HP最大時に自然回復ログが出ない。
- 自然回復時にHP表示が更新され、`+1` の浮遊テキストが出る。

## 階層別出現

- 1Fではスライムのみ出る。
- 2Fではコウモリが混ざる。
- 3F以降ではゴーレムが混ざる。
- 4F以降では敵数が増える。
- 4F以降では鉄の剣が1Fより出やすい。
- 敵、アイテム、階段、開始位置が重ならない。

## 全滅と再挑戦

- 敵に倒されるとゲームオーバー画面が出る。
- 空腹で倒れると空腹用の死因が出る。
- 敵種ごとの死因が出る。
- 戦績に到達階層、レベル、撃破数、経験値、経過ターン、装備が表示される。
- ゲームオーバー中は移動、足踏み、持ち物使用ができない。
- `R` で再挑戦できる。
- 再挑戦後、持ち物、装備、床アイテム、戦績、演出状態が前回から残らない。

## 音

- 初期状態では音が鳴らない。
- `音 OFF` ボタンを押すと `音 ON` に変わる。
- 音ON時、移動、攻撃、ヒット、被ダメージ、拾得、使用、階段、全滅でSEが鳴る。
- 音ON時、控えめなBGM/環境音が鳴る。
- `音 ON` ボタンを押すと `音 OFF` に戻り、音が止まる。
- 音OFFでもゲーム進行は壊れない。
