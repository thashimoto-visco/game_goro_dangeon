# Phase 5 詳細プラン: 全滅時の演出とリトライ導線

## Phase 5の目的

HP 0時の体験を、ログだけの終了から、暗転、倒れ演出、戦績表示、再挑戦導線を含むゲームオーバー画面へ強化する。

Phase 4で持ち物・装備が入ったため、全滅時には到達階層だけでなく、撃破数、経験値、経過ターン、装備武器も表示し、プレイ結果がひと目で分かるようにする。

## スコープ

- `state.gameOver` の追加
- HP 0検知の共通化
- 全滅時のプレイヤー倒れ演出
- 赤フラッシュ、画面シェイク、暗転オーバーレイ
- 戦績パネル表示
- `R` キー再挑戦時の状態初期化
- README更新

## 非スコープ

- セーブ/スコアランキング
- 持ち物の持ち越し
- 全滅専用スプライトの新規制作
- 音声演出

## 状態設計

`state.gameOver` を追加する。

```js
gameOver: {
  active: false,
  age: 0,
  duration: 900,
  reason: "",
}
```

通常時は `active: false` とし、HP 0になった瞬間に `startGameOver(reason)` を呼ぶ。

## 戦績

Phase 5で表示する戦績:

- 到達階層
- 撃破数
- 経験値
- 経過ターン
- 装備武器

`state.stats` を追加する。

```js
stats: {
  turns: 0,
  defeated: 0,
}
```

`tickTurn()` でターン数を増やし、敵撃破時に撃破数を増やす。

## HP 0検知

HP 0は以下から発生する。

- 敵の通常攻撃
- 敵の反撃
- 空腹ダメージ

それぞれで個別にログを出すのではなく、ダメージ反映後に `handlePlayerDefeat(reason)` を呼ぶ。

## 死因文言

ゲームオーバー画面の見出しは固定の「全滅」ではなく、死因文言を表示する。

死因文言は `defeatReasons` に集約する。

```js
const defeatReasons = {
  hunger: "吾郎は空腹で倒れた",
  enemy: {
    slime: "吾郎はぬるぬるになった",
    bat: "吾郎はバサバサになった",
    golem: "吾郎はゴロ岩につぶされてしまった",
  },
  fallbackEnemy: "吾郎は力尽きた",
};
```

今後モンスターや罠、毒、落石などの全滅原因が増えた場合も、このテーブルに原因キーと表示文言を追加する。

## 入力

- ゲームオーバー中は移動、足踏み、持ち物使用を受け付けない。
- `R` キーはゲームオーバー中のみ受け付ける。
- 再挑戦時は階層、HP、満腹度、経験値、持ち物、装備、床アイテム、戦績、演出状態を初期化する。

## 描画

### 倒れ演出

専用倒れスプライトがまだ無いため、Phase 5では既存の吾郎スプライトを回転・沈み込み・暗め表示して倒れた印象を作る。

### オーバーレイ

暗転は `drawOverlayLayer()` に統合する。

表示内容:

- `ゲームオーバー`
- 死因文言
- 到達階層
- 撃破数
- 経験値
- 経過ターン
- 装備
- `Rキーで再挑戦`

## 実装タスク

1. Phase5詳細プランを追加。
2. `state.gameOver` と `state.stats` を追加。
3. HP 0検知の共通関数を追加。
4. `tickTurn()` と撃破処理で戦績を更新。
5. ゲームオーバー中の入力抑制を追加。
6. 倒れ演出をプレイヤー描画に追加。
7. 暗転と戦績パネルを描画。
8. 再挑戦時の初期化を強化。
9. READMEを更新。
10. 静的確認と手動確認。

## 受け入れ条件

- HP 0時に暗転つきのゲームオーバー表示へ遷移する。
- 戦績が表示される。
- ゲームオーバー中に移動やアイテム使用ができない。
- `R` キーで新しいプレイを開始できる。
- 再挑戦後に前回の演出、持ち物、装備、床アイテム、戦績が残らない。
- 既存の移動、攻撃、階段、アイテム使用が壊れていない。

## Phase 6への引き継ぎ

Phase 6では、全滅演出にSE/BGMを追加し、敵ステータスやアイテム出現率を調整する。Phase 5の戦績表示は、バランス調整時の確認にも使える。
