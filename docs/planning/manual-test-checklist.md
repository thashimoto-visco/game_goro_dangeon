# 手動テストチェックリスト

## 起動

- `index.html` をブラウザで開ける。
- コンソールにerror/warningが出ない。
- 画面にゲーム画面、ステータス、持ち物、ログ、音ボタンが表示される。
- 初期状態で音ボタンが `音 OFF` になっている。

## 基本操作

- 矢印キーまたはWASDで移動できる。
- 移動に合わせてカメラがスクロールする。
- `Space` で足踏みできる。
- 壁には移動できない。

## 戦闘

- 隣接する敵方向へ移動入力すると通常攻撃になる。
- 攻撃モーション、斬撃、ヒット表示が出る。
- 敵が生きている場合、反撃が発生する。
- 敵を倒すと撃破演出とログが出る。
- 敵種ごとにHP/攻撃力の違いが感じられる。

## アイテム

- 床アイテムが見える。
- アイテム上に移動すると拾える。
- 拾ったアイテムが持ち物に表示される。
- `1`-`9` で武器を装備できる。
- `1`-`9` で食料と回復薬を使える。
- 持ち物が9個のとき、追加アイテムを拾えない。
- 階段とアイテムが同じマスに出ない。

## 階段

- 階段に乗ると次の階へ進む。
- 次の階で床アイテムと敵が再配置される。
- 持ち物と装備は階層移動後も維持される。

## 全滅と再挑戦

- 敵に倒されるとゲームオーバー画面が出る。
- 空腹で倒れると空腹用の死因が出る。
- 敵種ごとの死因が出る。
- 戦績に到達階層、撃破数、経験値、経過ターン、装備が表示される。
- ゲームオーバー中は移動、足踏み、持ち物使用ができない。
- `R` で再挑戦できる。
- 再挑戦後、持ち物、装備、床アイテム、戦績、演出状態が前回から残らない。

## 音

- 初期状態では音が鳴らない。
- `音 OFF` ボタンを押すと `音 ON` に変わる。
- 音ON時、移動、攻撃、ヒット、被ダメージ、拾得、使用、階段、全滅でSEが鳴る。
- 音ON時、控えめなBGM/環境音が鳴る。
- `音 ON` ボタンを押すと `音 OFF` に戻り、音が止まる。
- 音OFFでもゲーム進行は壊れない。
