# Phase 6 詳細プラン: バランス、音、仕上げ

## Phase 6の目的

Phase 1からPhase 5で入れた見た目、戦闘、アイテム、全滅演出を、1本の短いゲーム体験として自然につなげる。

このフェーズの中心は「新機能を大きく増やす」ことではなく、数階層ぶん遊んだときに、戦闘、拾得、使用、装備、階段、全滅、再挑戦が破綻せず、気持ちよく回る状態へ磨くこと。

## 現状

- スクロールするタイルマップがある。
- プレイヤーとMOBは大きめに表示される。
- 攻撃モーション、ヒット、撃破演出がある。
- 床アイテム、持ち物、武器、食料、回復薬がある。
- 全滅時の死因表示、戦績、リトライがある。
- 音は未実装。
- バランスは仮設定のまま。
- 手動確認項目は各Phase文書に散っている。

## スコープ

## 目標体験

- 1Fから3F程度まで、初見でも何をすればよいか分かる。
- 敵に殴られ続けるだけで即終了せず、食料や回復薬を使う余地がある。
- 武器を拾うと明確に強くなったことが分かる。
- 空腹、敵攻撃、階段移動が自然なテンポで進む。
- 攻撃、拾得、使用、階段、全滅に最低限の音が鳴る。
- 音が必要なときだけ画面上のボタンで有効化できる。

## バランス方針

### 敵ステータス

現在は敵種ごとの差が少ないため、種別ごとの役割を作る。

- ぬるりスライム: 低HP、低攻撃。序盤の基本敵。
- バサバサコウモリ: 低HP、中攻撃。やや危険。
- ゴロ岩ゴーレム: 高HP、高攻撃。避けたい敵。

候補:

```js
const monsterTypes = [
  { key: "slime", name: "ぬるりスライム", baseHp: 5, baseAtk: 2, hpScale: 1, atkScale: 0.35 },
  { key: "bat", name: "バサバサコウモリ", baseHp: 4, baseAtk: 3, hpScale: 0.8, atkScale: 0.45 },
  { key: "golem", name: "ゴロ岩ゴーレム", baseHp: 9, baseAtk: 4, hpScale: 1.4, atkScale: 0.6 },
];
```

### アイテム出現率

Phase 4の出現率は仮。Phase 6では遊びやすさを優先する。

初期候補:

- おにぎり: 32%
- 薬草: 34%
- 木の棒: 24%
- 鉄の剣: 10%

回復薬を少し多めにして、短時間の手動テストで全滅までが早すぎないようにする。

### 効果量

- 木の棒: 攻撃+1
- 鉄の剣: 攻撃+3
- おにぎり: 満腹度+35
- 薬草: HP+10

まずは現状維持。必要ならPhase 6の手動テスト後に調整する。

## 音方針

外部音声アセットを増やさず、Web Audio APIで短いチップチューン風SEを生成する。

### SE候補

- 移動: 短い低音クリック
- 攻撃: 短いノイズ/矩形波
- ヒット: 高めの短音
- 撃破: 下降音
- 拾得: 明るい2音
- 使用/装備: 決定音
- 階段: 上昇アルペジオ
- ダメージ: 低い濁った音
- ゲームオーバー: 下降フレーズ

### BGM候補

Web Audioでごく短いループを作る。

- 低音ドローン
- 短いアルペジオ
- 音量は控えめ

ブラウザの自動再生制限があるため、最初のキー入力後にAudioContextを開始する。

### ミュート/音量ボタン

初期状態はミュートにする。

画面上にミュートボタンを追加し、クリックで音のON/OFFを切り替える。

方針:

- 初期表示は `音 OFF`
- クリックするとAudioContextを開始し、`音 ON` に変わる
- もう一度クリックすると `音 OFF` に戻る
- キーボードショートカットはPhase 6では必須にしない

ブラウザの自動再生制限があるため、最初の音ON操作をユーザー操作として扱う。

## リスクと対策

### リスク: 音がうるさい

対策:

- 初期音量を控えめにする。
- 画面上のボタンで即ミュートできるようにする。

### リスク: ブラウザ自動再生制限で音が鳴らない

対策:

- 最初のキー入力時にAudioContextを開始する。
- 音が鳴らなくてもゲーム進行は壊れないようにする。

### リスク: バランス調整が主観的になる

対策:

- まず3F到達までの手動確認を基準にする。
- 数値は小さく動かす。
- Phase 6以降も調整可能な定数に寄せる。

### リスク: `main.js` がさらに大きくなる

対策:

- Phase 6では単一ファイル維持を優先する。
- 音関連は `sound` オブジェクトと関数群にまとめ、後で分割しやすくする。
