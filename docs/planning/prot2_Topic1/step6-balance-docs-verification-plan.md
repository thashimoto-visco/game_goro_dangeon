## 確認方針

### 1F

目的:

- 操作確認と最初の成長導線。

確認すること:

- 敵はスライムのみ。
- 敵数は3から4体程度。
- アイテムは3から5個程度。
- いきなり理不尽に倒されない。
- スライム撃破で経験値が入る。
- 経験値表示が `現在 / 次` で更新される。

目安:

- 1F終了時にレベル1後半、またはレベル2手前。
- 全敵撃破した場合はレベル2になってもよい。

### 2F

目的:

- コウモリが混ざり、敵の違いが見え始める。

確認すること:

- スライムとコウモリが出る。
- ゴーレムはまだ出ない。
- レベルアップログとHP全回復が自然に感じられる。
- 回復薬や食料を使う余地がある。

目安:

- 2F終了時にレベル2。
- 装備がなくても探索継続できる。

### 3F

目的:

- ゴーレムが低確率で混ざり、危険な敵の存在が見え始める。

確認すること:

- スライム、コウモリ、低確率のゴーレムが出る。
- ゴーレムが出ても即死級ではない。
- HP自然回復が少し役立つ。
- 足踏み回復中も敵行動があるため安全ではない。

目安:

- 3F終了時にレベル2から3。
- 回復アイテムや装備の価値が分かる。

### 4F

目的:

- 敵数とゴーレム比率が上がり、HP管理が必要になる。

確認すること:

- 敵数が5から6体程度。
- コウモリとゴーレムの圧が増える。
- 鉄の剣が出た時に突破しやすくなる。
- 薬草、おにぎり、自然回復が噛み合う。

目安:

- 無装備、低アイテム時は危険。
- 装備や回復があれば突破可能。

### 5F

目的:

- Topic 1時点の短期目標地点として、成長と消耗の流れが成立しているか確認する。

確認すること:

- 敵数が5から7体程度。
- ゴーレム比率が上がる。
- レベル3前後で到達できる。
- HP、食料、回復薬、装備の状態で生存感が変わる。
- 即死でも退屈でもない。

目安:

- 5F到達時にレベル3前後。
- 回復や装備が噛み合えば継続できる。
- 事故は起きるが、理不尽すぎない。

## 数値調整ルール

Step 6では、全部を完璧に合わせようとしない。

調整してよいもの:

- `floorEnemyTables` の `count`
- `floorEnemyTables` の `weight`
- `floorItemTables` の `count`
- `floorItemTables` の `weight`
- 敵経験値
- レベルテーブルの `nextExp`

原則として、1回の調整で大きく変えない。

例:

- 敵数を `[5, 7]` から `[5, 6]` にする。
- ゴーレム weight を35から30にする。
- 薬草 weight を30から34にする。

調整しないもの:

- 戦闘式そのもの。
- マップ生成方式。
- アイテム種別の追加。
- 敵AI。

## 手動テストチェックリスト更新内容

`docs/planning/prot1/manual-test-checklist.md` に以下を追加する。

### レベルと経験値

- 敵を倒すと経験値が増える。
- 敵種ごとに獲得経験値が異なる。
- 経験値が必要値に達するとレベルアップする。
- レベルアップ時にHPが最大まで回復する。
- レベルアップ時に最大HP、攻撃、守備が更新される。
- レベルアップ時にログ、浮遊テキスト、SE、フラッシュが出る。
- リトライ時にレベルと経験値が初期化される。

### 自然回復

- 満腹度90以上では自然回復が早い。
- 満腹度70から89では自然回復する。
- 満腹度30から69では自然回復が遅い。
- 満腹度29以下では回復進捗が増えない。
- 満腹度0では空腹ダメージのみで自然回復しない。
- HP最大時に自然回復ログが出ない。

### 階層別出現

- 1Fではスライムのみ出る。
- 2Fではコウモリが混ざる。
- 3F以降ではゴーレムが混ざる。
- 4F以降では敵数が増える。
- 4F以降では鉄の剣が1Fより出やすい。
- 敵、アイテム、階段、開始位置が重ならない。

### 全滅と再挑戦
