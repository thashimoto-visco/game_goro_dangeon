## 現在の成長仕様

レベルアップは累計経験値で判定する。

```js
const levelTable = [
  { level: 1, nextExp: 8, maxHp: 20, atk: 5, def: 2 },
  { level: 2, nextExp: 20, maxHp: 24, atk: 6, def: 2 },
  { level: 3, nextExp: 38, maxHp: 29, atk: 7, def: 3 },
  { level: 4, nextExp: 62, maxHp: 34, atk: 8, def: 3 },
  { level: 5, nextExp: 92, maxHp: 40, atk: 9, def: 4 },
  { level: 6, nextExp: 128, maxHp: 46, atk: 10, def: 4 },
];
```

レベルアップ時は、新しい最大HPまで全回復する。これはプレイヤーへのサービスとして採用した。難度低下は後続の強敵や階層設計で受け止める。

## 現在の自然回復仕様

自然回復は24ポイントの進捗式。

- 満腹度90以上: 1ターンごとに進捗+4。
- 満腹度70から89: 1ターンごとに進捗+3。
- 満腹度30から69: 1ターンごとに進捗+2。
- 満腹度1から29: 進捗増加なし。
- 満腹度0: 空腹ダメージのみ。進捗増加なし。

進捗が24以上になったらHPを1回復し、進捗を0に戻す。

満腹度29以下に下がっても、既存の回復進捗はリセットしない。境界をまたいだ時の損失が大きすぎないようにするため。

## 現在の敵出現方針

- 1F: スライムのみ。
- 2F: スライム中心、コウモリが混ざる。
- 3F: スライム、コウモリ、低確率のゴーレム。
- 4F: 敵数とゴーレム比率が少し上がる。
- 5F以降: 暫定でコウモリとゴーレムの比率を高める。

新敵を追加する場合は、`monsterTypes` に定義を追加し、出したい階層の `floorEnemyTables` に `{ type, weight }` を追加する。

## 現在のアイテム出現方針

- 1F: 薬草とおにぎりを厚めにし、鉄の剣は低確率。
- 2Fから3F: 現状に近い比率。
- 4F以降: 鉄の剣がやや出やすい。

新アイテムを追加する場合は、`itemTypes` に定義を追加し、出したい階層の `floorItemTables` に `{ type, weight }` を追加する。

## 残す判断

### 本格バランス調整はまだしない

Topic 1では「遊べる基礎」を整えるところまでに留める。

レベルアップ全回復、自然回復、鉄の剣出現率などで難度が下がる可能性はあるが、強敵、イベント、追加アイテムが揃う前に細かく詰めすぎない。

### 強敵で難度の山を作る

難度低下や緊張感不足は、Topic 4「強敵と階層メリハリ」で受け止める。

強敵は以下と相性がよい。

- レベルアップによる成長。
- 高めの経験値報酬。
- 撃破報酬。
- 接近警告ログ/SE。
- 通常敵とは違う見た目。

### Topic 2ではシステムを大きく変えない

次のTopic 2は「グラフィックス基準の再整理」なので、ゲームシステムの数値や生成ロジックはなるべく固定したまま、見た目の統一に集中する。

## Topic 2への引継ぎ

Topic 2では、以下を優先するとよい。

1. 吾郎、敵、アイテム、タイル、UIのサイズ基準を整理する。
2. プレイヤーと敵の足元基準、影、描画サイズを揃える。
3. レベルアップ、自然回復、撃破、被ダメージなどの既存演出が同じ絵柄で見えるようにする。
4. 階層別出現により敵種を見る機会が増えたため、スライム、コウモリ、ゴーレムの視認性を優先して整える。
5. アイテム出現テーブルが階層別になったため、木の棒、鉄の剣、おにぎり、薬草のアイコン識別性を上げる。

## Topic 2で注意すること

- 既存のレベル/経験値/自然回復/出現テーブルは、Topic 2ではなるべく触らない。
- 素材差し替えで当たり判定や配置ルールを変えない。
- スプライトの見た目サイズを変える場合も、グリッド上の位置と足元基準は維持する。
- UIの見た目を変える場合も、レベル、経験値、次レベル、HP、満腹度、装備が読みやすいことを優先する。
