# Topic 1 Step 3 詳細プラン: UIとレベルアップ演出

## 目的

Step 2で実装したレベルアップと経験値獲得を、プレイヤーが常に理解できる表示と演出にする。

このステップでは、ステータス欄にレベルと次レベル情報を追加し、全滅戦績にも到達レベルを表示する。あわせて、レベルアップ時のSEと軽い画面フラッシュを追加して、成長した瞬間の手触りを強くする。

## 前提

Step 2で以下が実装済みであること。

- `gainExp(amount)`
- `canLevelUp()`
- `applyLevelUp(nextEntry)`
- 敵撃破時の `gainExp(enemy.exp)`
- レベルアップ時のHP全回復
- レベルアップログ
- `Lv UP` 浮遊テキスト

## 対象範囲

- ステータス欄に `レベル` を追加する。
- 経験値表示を `現在 / 次` 形式にする。
- 最大レベル時の経験値表示を自然にする。
- `ui` 参照にレベル表示要素を追加する。
- `updateUi()` でレベルと経験値表示を更新する。
- 全滅画面の戦績にレベルを追加する。
- レベルアップ専用SEを追加する。
- レベルアップ時に薄い金色フラッシュを出す。
- レベルアップ時のログがUI追加後も過剰すぎないか確認する。

## 非対象

- HP自然回復。
- 階層別敵/アイテムテーブル。
- 経験値テーブルの再調整。
- UIデザインの大幅変更。
- ステータス欄のレイアウト全面改修。
- レベルアップ専用アニメーション画像の追加。

## 変更対象

- `index.html`
  - ステータス欄の `レベル` 行追加
- `main.js`
  - `ui.level`
  - `updateUi()`
  - `drawGameOverLayer()`
  - `playSound(name)`
  - `applyLevelUp(nextEntry)`

CSSは原則変更しない。既存の `dl` レイアウトで収まる想定とする。

## UI表示方針

### ステータス欄

現在:

```html
<div><dt>階層</dt><dd id="floor">1F</dd></div>
<div><dt>HP</dt><dd id="hp">20 / 20</dd></div>
<div><dt>攻撃</dt><dd id="atk">5</dd></div>
<div><dt>守備</dt><dd id="def">2</dd></div>
<div><dt>満腹度</dt><dd id="hunger">100</dd></div>
<div><dt>経験値</dt><dd id="exp">0</dd></div>
```

Step 3後:

```html
<div><dt>階層</dt><dd id="floor">1F</dd></div>
<div><dt>レベル</dt><dd id="level">1</dd></div>
<div><dt>HP</dt><dd id="hp">20 / 20</dd></div>
<div><dt>攻撃</dt><dd id="atk">5</dd></div>
<div><dt>守備</dt><dd id="def">2</dd></div>
<div><dt>満腹度</dt><dd id="hunger">100</dd></div>
<div><dt>経験値</dt><dd id="exp">0 / 8</dd></div>
```

レベルは階層の直下に置く。ローグライクでは階層とレベルの比較が重要なので、近くにある方が見やすい。

### 経験値表示

通常:

- `0 / 8`
- `9 / 20`
- `38 / 62`

最大レベル時:

- `128 / --`

最大レベル後も累計経験値は増えるため、左側は現在経験値、右側は `--` とする。

## `ui` 参照

`main.js` の `ui` に `level` を追加する。

```js
level: document.getElementById("level"),
```

## 経験値表示ヘルパー

`updateUi()` 内で直接書いてもよいが、表示ルールが少しだけあるためヘルパー化すると読みやすい。

候補:

```js
function expDisplayText() {
  const requiredExp = nextLevelExp(state.player.level);
  return requiredExp === null ? `${state.player.exp} / --` : `${state.player.exp} / ${requiredExp}`;
}
```

`nextLevelExp()` はStep 1で実装済み。

## `updateUi()` 更新

候補:

```js
ui.level.textContent = state.player.level;
ui.exp.textContent = expDisplayText();
```

既存の `ui.exp.textContent = state.player.exp;` を置き換える。

## 全滅画面

現在の戦績:

```js
const lines = [
  `到達階層: ${state.floor}F`,
  `撃破数: ${state.stats.defeated}`,
  `経験値: ${state.player.exp}`,
  `経過ターン: ${state.stats.turns}`,
  `装備: ${currentWeaponName()}`,
];
```

Step 3後:

```js
const lines = [
  `到達階層: ${state.floor}F`,
  `レベル: ${state.player.level}`,
  `撃破数: ${state.stats.defeated}`,
  `経験値: ${state.player.exp}`,
  `経過ターン: ${state.stats.turns}`,
  `装備: ${currentWeaponName()}`,
];
```

行数が5行から6行になる。現在のゲームオーバーパネル高は `292` なので、必要に応じて以下を調整する。

- `panelHeight`
- 戦績行の開始Y
- 行間
- `Rキーで再挑戦` の位置

候補として、まずは `panelHeight` を `312` に広げる。戦績開始位置は維持し、行間は `23` から `24` 程度で確認する。

## レベルアップSE

`playSound(name)` に `levelUp` を追加する。

候補:

```js
if (name === "levelUp") {
  playTone(523, 0.07, "triangle", 0.09);
  playTone(659, 0.08, "triangle", 0.09, 0.06);
  playTone(784, 0.12, "square", 0.08, 0.13);
  return;
}
```

方針:

- 階段SEより少し明るい。
- 長すぎない。
- ミュート時は既存の `playSound()` と同じく鳴らない。

## レベルアップフラッシュ

`applyLevelUp(nextEntry)` の中で以下を追加する。

```js
playSound("levelUp");
startFlash("rgba(250, 204, 21, 0.2)", 160);
```

方針:

- 金色系の薄いフラッシュにする。
- ダメージ時の赤フラッシュより柔らかくする。
- 複数レベルアップ時は複数回呼ばれる可能性があるが、Topic 1序盤では頻度が低いため許容する。

## ログ調整

Step 2のログ:

- `吾郎はレベル2になった！`
- `最大HP 20→24 / 攻撃 5→6 / 守備 2→2`

Step 3では一旦維持する。

UIでレベルと経験値が見えるようになるため、もしログが長すぎると感じたら後続で以下に短縮する。

- `最大HP 24 / 攻撃 6 / 守備 2`

ただし、初期実装では成長差分が見える方を優先する。

## 完了条件

- ステータス欄にレベルが表示される。
- 起動直後はレベル1と表示される。
- 経験値が `現在 / 次` 形式で表示される。
- レベルアップ後、レベル表示と経験値表示が更新される。
- 最大レベル時は経験値表示が `現在 / --` になる。
- 全滅画面に到達レベルが表示される。
- レベルアップ時に専用SEが鳴る。
- レベルアップ時に薄い金色フラッシュが出る。
- 既存のHP、攻撃、守備、満腹度、装備表示が壊れていない。
- 既存のゲームオーバー表示が崩れていない。

## 確認方法

### 初期表示

- 起動する。
- ステータス欄に `レベル 1` が表示される。
- 経験値が `0 / 8` と表示される。
- HP、攻撃、守備、満腹度、装備が従来通り表示される。

### レベルアップ表示

- 敵を倒して経験値を得る。
- 経験値表示が増える。
- 経験値8以上でレベルアップする。
- レベル表示が `2` になる。
- HPが `24 / 24` になる。
- 攻撃が `6` になる。
- ログと `Lv UP` 浮遊テキストが出る。
- 音ON時にレベルアップSEが鳴る。
- 金色フラッシュが赤ダメージフラッシュと混同しにくい。

### 全滅表示

- レベルアップ後に全滅する。
- ゲームオーバー画面にレベルが表示される。
- 6行になっても文字が重ならない。
- `Rキーで再挑戦` が見切れない。

### リトライ表示

- `R` で再挑戦する。
- レベルが1へ戻る。
- 経験値が `0 / 8` へ戻る。
- HP、攻撃、守備が初期値へ戻る。

## リスクと対策

### リスク: ステータス欄が縦に詰まる

対策:

- まずは既存レイアウトに1行追加するだけにする。
- 詰まる場合は `経験値` 表示を短くする。
- CSSの大幅変更は避ける。

### リスク: ゲームオーバーパネルに戦績が収まらない

対策:

- `panelHeight` を少し増やす。
- 戦績行の行間を少し詰める。
- それでも厳しい場合は `経験値` と `経過ターン` の表示を短くする。

### リスク: レベルアップSEが他のSEより目立ちすぎる

対策:

- 音量を控えめにする。
- 階段SEより少し明るい程度にする。
- ミュート時は鳴らない既存仕様を維持する。

### リスク: フラッシュがダメージ演出と紛らわしい

対策:

- 赤ではなく薄い金色にする。
- durationは短めにする。
- 透明度を上げすぎない。
